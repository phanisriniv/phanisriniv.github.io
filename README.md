# Sabnaveesu Phani Srinivas — Portfolio

A responsive, static portfolio website designed for GitHub Pages.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open the repository: https://github.com/phanisriniv/phanisriniv.github.io
3. Upload/replace `index.html`, `styles.css`, and the `assets` folder in the repository root.
4. Commit the changes to the `main` branch.
5. GitHub Pages will publish the updated site automatically.

Keep the folder structure intact:
- `index.html`
- `styles.css`
- `assets/profile.jpeg`

The current published website remains unchanged until you upload and commit these replacement files.
