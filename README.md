# Sabnaveesu Phani Srinivas — Portfolio

A responsive, static portfolio website built with HTML and CSS.

## Publish with GitHub Pages

1. Create a public repository named `phanisriniv.github.io`.
2. Upload `index.html` and `styles.css` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the deployment to finish. The website should be available at:

   `https://phanisriniv.github.io`

## Before publishing

Review all contact details, dates, project descriptions and credential links. Add only project screenshots and files that do not expose passwords, tokens, private IP addresses, internal hostnames or other confidential information.
